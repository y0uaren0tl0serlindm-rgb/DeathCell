# 怎么画模板房间

一层关卡 = 若干块**手绘模板块**横向拼起来。你画块，程序负责挑块、验接缝、摆门。

```bash
godot --headless --path . res://tests/chunk_test.tscn   # 画完就跑这个
```

它会把每一块跑一遍可达性搜索，**直接告诉你哪个平台跳不上去**，
出错时把你画的图重新打印一遍并标出问题格子。判据不是谁拍脑袋定的，
是 `JumpModel` 从 `player.gd` 的物理常数模拟出来的跳跃包络 ——
和游戏里真实跳跃用的是同一套数字，改了跳跃参数它自己会跟着变。

---

## 文件长什么样

一个块一个文件，放在 `assets/levels/chunks/*.room`。`---` 之前是头部，之后是网格。

```
name: 断桥
tags: combat
depth: 2-
weight: 1.5
---
########################
........................
（一共 24 行）
```

| 头部字段 | 必填 | 说明 |
|---|---|---|
| `name` | 否 | 显示名，报错和日志里用。不写就取文件名 |
| `tags` | 否 | 逗号分隔的自由标签，现在只是备注 |
| `depth` | 否 | 出现在哪几层：`3`（只在第 3 层）/ `2-5`（区间）/ `2-`（第 2 层起）。不写 = 所有层 |
| `weight` | 否 | 抽中的相对权重，默认 1.0。想让某块少见就写 0.5 |

## 图例

| 字符 | 含义 |
|---|---|
| `#` | 实心地形 |
| `.` | 空气 |
| `<` | **左接口落脚点** —— 必须有且只有一个，必须在第一列 |
| `>` | **右接口落脚点** —— 必须有且只有一个，必须在最后一列 |
| `n` | 小兵刷点（这一格算空气） |
| `N` | 精英刷点（这一格算空气） |

## 尺寸硬性要求

- **正好 24 行**，一行都不能多不能少（等于 `LevelGrid.H`）。
- 宽度 8~48 列，**每行必须一样宽**。示例块都是 24 列，照着抄最省事。
- **第 1 行和第 24 行必须整行都是 `#`** —— 上下不封死玩家会掉出世界。
- 左右两侧**不要**画墙：那是接缝，要留给下一块接上去。整层最外面的封边由程序加。

## 三条决定成败的规则

### 1. 平台高度不能超过 3 格

一次跳跃最多上升 **3 格**（`chunk_test` 每次都会把这个数字打在最前面，以它为准）。
落脚点比出发点高 4 格 = 画得出来站不上去。这个坑这个项目已经踩过两次（issue #7）。

### 2. 平台正下方是跳不上去的

玩家会顶到平台底面。真实路线是**在台子旁边起跳、再落到台面上**。
所以摆平台时看的不是"台子下面那一列"，而是**紧挨台子边缘外侧的那一列**——
那一列必须站得住人，而且从它到台面不超过 3 格。

而且起跳那一列**头顶要一路空到落点高度**，不然身体会撞在台子侧面。
下面这个是我画第一版断桥时踩的，`chunk_test` 当场标了出来：

```
错的                            对的
13 .....####...........   →    13 ......####..........
14 ........................    14 ........................
15 ........................    15 ........................
16 ....####............        16 ....####............
```

左边：从下层台面 (第 4 列) 想上到 (第 5 列)，可第 5 列正上方就是上层平台，
身体宽度会扫到它 —— 上不去。右边把上层往右挪一格，让第 4、5 列一路空着，就通了。

### 3. 缺口不能超过 6 格

平地起跳最远横跨 **6 格**。断桥、岩浆池这种缺口画到 5 格以内比较稳妥，
6 格要求近乎完美的操作。

## 接缝：块和块怎么接上

拼接时下一块直接贴在上一块右边。判据只有一条：

> 从上一块的 `>` **往右走一格**落到下一块的 `<`，
> 这一步必须是跳跃包络里真实存在的移动。

所以 `<` 和 `>` 在哪一行，就决定了这块能接在谁后面、谁能接在它后面：

- **两边都放在同一行**（示例里是第 19 行）→ 平接，能和绝大多数块互相接。**默认这么画。**
- `>` 比 `<` 高很多 → 这块结束在高处，只有入口同样在高处的块能接在它后面（`shaft.room` 就是这样）。
- `>` 比 `<` 低 → 下一块要往上爬。**上升超过 3 格就永远接不上了**。

`chunk_test` 会打出一张接缝表，告诉你每一块后面能接哪些块：

```
接缝（从上一块的 `>` 往右走一格到下一块的 `<`）：
  断桥           → 断桥, 前厅, 柱林, 竖井
  竖井           → 断桥, 阶梯下行, 前厅, 柱林, 竖井
```

某一块后面一个都接不上、或者没人能接在它前面，会直接报失败 ——
那块画了也永远不会出现在游戏里。

## 刷怪点

`n` / `N` 标在**玩家站得住、而且够得着**的格子上，否则 `chunk_test` 会报错
（够不着的怪只会隔着地形放冷枪）。

作者标的刷怪点优先使用；数量不够这一层需要的敌人数时，剩下的由程序在可达落脚点里随机补。
所以你可以只标关键位置（露台上的弓手、隘口的精英），其余交给程序。

## 现有的块

| 文件 | 作用 | 接口 |
|---|---|---|
| `entry_hall.room` | 平坦大厅，起手用，权重最高 | 平接 |
| `broken_bridge.room` | 中间一个坑 + 两层平台 | 平接 |
| `pillars.room` | 柱林，适合打架，精英站柱顶 | 平接 |
| `shaft.room` | 阶梯上行，结束在高处 | 出口在高处 |
| `descent.room` | 阶梯下行，从高处回到地面 | 入口在高处 |

想加一块最快的办法：复制 `entry_hall.room` 改个名字，在里面画。

## 生成器开关

`LevelGrid.generator` 有三个值，默认 `CHUNKS`：

| 值 | 行为 |
|---|---|
| `CHUNKS` | 拼模板块（默认）。拼不出通路时**自动退回 `AGENT`**，游戏不会因为块不够而卡住 |
| `AGENT` | 智能体挖掘的洞穴，无限随机 |
| `HEIGHTMAP` | 老的高度图走廊，留着做 A/B 对比 |

静默退回是最难发现的问题，所以 `generation_test` 和 `chunk_test` 都会把
"有房间退回了智能体挖掘"当作**失败**报出来。
